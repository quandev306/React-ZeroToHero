# 🚀 Mini Project: Personal Landing Page

## 🎯 Mục Tiêu

Áp dụng tất cả kiến thức CSS đã học để xây dựng một Landing Page hoàn chỉnh:
- Box Model
- Flexbox
- Grid
- Responsive Design

---

## 📋 Yêu Cầu

### Cấu trúc trang

1. **Navigation Bar**
   - Logo bên trái
   - Menu bên phải
   - Sticky on scroll
   - Responsive (hamburger menu on mobile)

2. **Hero Section**
   - Heading lớn với gradient text
   - Subtitle
   - Call-to-action button
   - Background gradient hoặc image

3. **Features/Services Section**
   - Grid 3 cards
   - Icon + Title + Description
   - Hover effects

4. **About Section**
   - 2 columns: Image + Text
   - Responsive (stack on mobile)

5. **Testimonials**
   - Cards với quotes
   - Avatar + Name

6. **Contact Form**
   - Input fields styled
   - Submit button

7. **Footer**
   - Multi-column layout
   - Social links
   - Copyright

---

## 🎨 Design Guidelines

### Colors
```css
:root {
  --primary: #667eea;
  --secondary: #764ba2;
  --dark: #1a1a2e;
  --light: #f5f7fa;
  --text: #333;
  --text-light: #666;
}
```

### Typography
- Heading: Bold, large
- Body: Regular, readable
- Use `rem` units

### Effects
- Smooth transitions (0.3s)
- Box shadows for depth
- Hover states on buttons và cards
